Why Shale is different

A mining algorithm designed by AI

Built like rock

Every two weeks the network lays down a 6 GiB dataset in layers, each mixed from random pieces of the layers beneath. Mining hops through it at random, 32 reads per attempt. Speed comes from memory, which GPUs and CPUs already have and custom chips cannot make much faster.

No shortcut

Older memory-hard algorithms let any piece of the dataset be computed on its own, so nodes can check blocks cheaply. That also gives attackers a shortcut. Shale's dataset can only be built in order. Nodes keep a small fingerprint instead, and every block carries a receipt of what it read.

Designed and attacked by agents

Independent AI designers proposed, hostile AI critics attacked, and auditors checked every novelty claim with logged searches. The result is one genuinely new mechanism, stated as "no prior art found", not "proven first".

Shale is verified inside the Solana program itself, using the same code as the miner. A copied solution cannot steal a reward: the winner's key is part of the work.
